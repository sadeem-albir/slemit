requirements:
    pygame
    numpy

Make sure both main.py and util.py are on the same folder.
Then, run "python main.py" on cmd or terminal, or run it in
your preferred IDE/text editor.

buttons:
    move: w, a, d
    light on/off: l
    change ball color: k
    high beam: ]
    shuffle-effect: t
    turbo: shift
